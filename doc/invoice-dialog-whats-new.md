# Estimates and invoices

## Dialog improvements

- New look for the Invoice/Estimate and Settings dialog.
- The dialog is responsive and adapts to the different sizes on desktop, smartphone and tablet.
- Added a **⋮** context menu on every row of the items table when the window is narrow.
- A banner marks read only documents.
- Added a scroll bar under the items table.

## Fixes

- In the dialog, fixed the texts shown when editing or creating an estimate.
- In the items table:
  - Fixed the display of the column titles and of the rows when the window is resized.
  - Fixed the Description cell not adapting when text is typed on several lines.
  - Fixed data entry in the last row of the table, which in some cases cleared the content.
